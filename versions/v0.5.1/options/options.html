Языки ответов

Ответы переводятся только на отмеченные языки. Входящие сообщения переводятся с любого языка. Если собеседник пишет на выключенном языке, ответ переводится на язык ниже.

Проверки перевода ответа

Интерфейс

Глоссарий

По строке на термин. Просто термин — не переводить. термин => ru: … | es: … | en: … — фиксированный перевод для указанных языков (для остальных языков переводит Google). Регистр не важен, ищутся целые слова. # — комментарий.


    


    

      
Провайдер перевода

      

        
        
        
        
      

      
Ключ Google Cloud: Google Cloud Console → проект с оплатой → включить «Cloud Translation API» → APIs & Services → Credentials → Create credentials → API key → ограничить ключ только «Cloud Translation API». Первые 500 000 символов в месяц бесплатно.

      

        
        
        
        
      

      

    


    

      
Перевод на устройстве (встроенный переводчик Chrome)

      
Переводит прямо в браузере: без интернета, без лимитов, тексты не уходят в Google. Качество ниже облачного, поэтому используется для чтения входящих и обратного перевода; ответ пользователю переводится в облаке. Если языковой пакет не скачан — автоматически используется облако.

      

        
        
      

      

        
        
        
      

      

    


    

      
Сайты и окна

      
Правило включается, если URL вкладки (или iframe с чатом) подходит под шаблон: * — любые символы, несколько шаблонов через запятую.
        Расширение работает только на доменах, к которым выдан доступ. Селекторы проще задать через popup расширения.

      

      
    


    

      
Импорт / экспорт

      
Для раздачи одинаковых настроек всей команде. API key в экспорт не попадает. После импорта каждому нужно выдать доступ к сайтам (кнопка у правила).
