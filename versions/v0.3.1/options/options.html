Интерфейс

Глоссарий

По строке на термин. Просто термин — не переводить. термин => ru: … | es: … | en: … — фиксированный перевод для указанных языков (для остальных языков переводит Google). Регистр не важен, ищутся целые слова. # — комментарий.

Сайты и окна

      
Правило включается, если URL вкладки (или iframe с чатом) подходит под шаблон: * — любые символы, несколько шаблонов через запятую.
        Расширение работает только на доменах, к которым выдан доступ. Селекторы проще задать через popup расширения.

      

      
    


    

      
Импорт / экспорт

      
Для раздачи одинаковых настроек всей команде. API key в экспорт не попадает. После импорта каждому нужно выдать доступ к сайтам (кнопка у правила).
