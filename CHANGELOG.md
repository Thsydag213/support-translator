# Changelog

## 0.2.0 — 2026-09-17 — готовность к пилоту

Добавлено:
- **Защита от отправки непереведённого текста.** Перехват Enter / Ctrl+Enter и клика по кнопке отправки. Мгновенная проверка по письменности (кириллица ↔ латиница и т.д.), для одинаковой письменности — определение языка (CLD → Google). Предупреждение: «Перевести» / «Отправить как есть» / «Отмена». Вставленный через панель перевод и короткие сообщения («ok», «спасибо») проходят без проверки.
- **Глоссарий**: термины «не переводить» и фиксированные переводы по языкам (`Кошелёк => ru: Кошелёк | es: Billetera`). Работает для входящих, исходящих и обратного перевода; проверка прямо в настройках.
- **Закрепление языка для тикета** (📌 в панели перевода). Тикет определяется по селектору ID тикета или по URL.
- **Язык собеседника только из его сообщений**: селектор «Сообщение пользователя» или список языков операторов (`operatorLangs`, по умолчанию `ru`).
- **Поддержка iframe**: скрипты работают во всех фреймах вкладки; команды popup и горячие клавиши доходят до нужного фрейма; выбор элементов работает внутри фрейма.
- **Доступ только к подключённым сайтам**: вместо `<all_urls>` — `optional_host_permissions` и динамическая регистрация скриптов. Кнопка «Подключить этот сайт» в popup, статус доступа и «Выдать доступ» у каждого правила в настройках.
- **Режим вставки «после сообщения»** — для сайтов, чей фреймворк не терпит чужих узлов внутри сообщений; автоудаление «осиротевших» подписей.
- **Статистика (из плана v0.3)**: история по дням (90 дней) — входящие/ответы по языкам, символы и запросы, кэш, ошибки, блокировки отправки. Страница статистики: плитки, график по дням, языки, оценка стоимости официального API, таблица, экспорт JSON/CSV, объединение файлов коллег для командных цифр.
- Popup: подключение сайта, статус по всем фреймам (язык собеседника, 📌, защита), пикеры «Кнопка отправки» и «ID тикета», ссылка на статистику.
- Настройки: новые поля правил, языки операторов, порог защиты, глоссарий, Ctrl+S, предупреждение о несохранённых изменениях.
- После обновления расширения старые скрипты на открытых вкладках сразу отключаются и просят обновить страницу.
- Тестовые страницы: `mock-iframe.html` (чат во фрейме с другого origin), `stats-preview.html` (статистика на демо-данных).

Изменено:
- Статистика хранится в `statsDays` (старый ключ `stats` 0.1.0 удаляется при обновлении).
- Кэш перевода учитывает версию глоссария.
- Тост после вставки перевода — вверху экрана (не перекрывает поле ввода).

Миграция с 0.1.0:
- После обновления расширение **не работает ни на одном сайте, пока не выдан доступ**: popup → «Подключить этот сайт» или настройки → «Выдать доступ» у правила.

## 0.1.0 — 2026-09-17 — прототип

Добавлено:
- Автоперевод входящих сообщений в заданных окнах (MutationObserver, правила сайтов по URL + CSS-селекторам).
- Подпись «🌐 Переведено: язык → язык», режимы «под оригиналом» / «вместо оригинала», копирование перевода.
- Локальное определение языка (встроенный в Chrome CLD) — английский не отправляется в переводчик.
- Перевод исходящего текста через панель подтверждения: оригинал / редактируемый перевод / обратный перевод с подсветкой расхождений; вставка только по подтверждению; «Вернуть оригинал».
- Автовыбор языка ответа по последнему иностранному сообщению в текущем окне.
- Поддержка textarea, input и contenteditable (совместимо с React/Vue за счёт insertText + input-событий).
- Провайдеры: Google free (translate.googleapis.com, gtx) и Google Cloud Translation v2 (ключ) с автофолбэком.
- Очередь (4 параллельных запроса), ретраи 429/5xx с экспоненциальной задержкой, дедупликация, кэш (память + storage.session).
- Popup: статус сайта, настройка окон кликом по странице, статистика за день.
- Страница настроек: языки, режим показа, провайдер, правила сайтов, импорт/экспорт.
- Горячие клавиши: Ctrl+Shift+Y — перевести ввод, Ctrl+Shift+U — перевести окно заново.
- Тестовый чат `test-site/mock-chat.html` и dev-стенд `?harness=1`.
