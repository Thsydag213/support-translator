# 01. Требования и нагрузка

## Контекст

- Среда: веб-сайт, похожий на мессенджер, где операторы тех.поддержки переписываются с пользователями.
- Сейчас перевод делается вручную через Google Translate (копировать → перевести → вставить). Качество Google команду устраивает — проблема в ручной работе и времени.

## Функциональные требования

| # | Требование | Как закрыто в 0.1.0 |
|---|---|---|
| F1 | Переводить на английский всё в **конкретных окнах** (не всю страницу) | Правила сайтов: `urlPattern` + `containerSelector` (окно) + `messageSelector` (сообщение) |
| F2 | **Подписывать**, что было переведено | Блок «🌐 Переведено: Испанский (es) → Английский» у каждого переведённого сообщения |
| F3 | Сообщения пользователей переводить, чтобы мы их понимали | Автоматически при появлении в окне (MutationObserver) |
| F4 | Переводить **введённый текст на месте** | Кнопка «🌐 Перевести» над полем ввода (сочетание клавиш — по желанию, chrome://extensions/shortcuts) |
| F5 | Исходящий перевод — **только с подтверждением** и **возможностью сравнить** | Панель: оригинал / редактируемый перевод / обратный перевод с подсветкой; вставка только по кнопке или Ctrl+Enter; автоотправки нет; «Вернуть оригинал» |
| F6 | Бесплатный вариант на базе Google | Провайдер `google-free` (translate.googleapis.com, client=gtx) |
| F7 | Хранить работу и версии в отдельной папке | `support-translator/`, `versions/`, `tools/release.ps1` |
| F8 | Не допустить отправки непереведённого ответа | v0.2: защита отправки (Enter / кнопка) с предупреждением |
| F9 | Термины продукта переводятся единообразно или не переводятся | v0.2: глоссарий |
| F10 | Работа, если чат во фрейме | v0.2: все фреймы, доступ к домену фрейма |
| F11 | Расширение не читает посторонние сайты | v0.2: доступ только к подключённым доменам |
| F12 | Данные для решения о провайдере и шаблонах | v0.2: статистика по языкам/объёмам, оценка стоимости |

## Нефункциональные требования

- Не ломать сайт: никаких `innerHTML` с переведённым текстом (защита от XSS), UI панели в Shadow DOM (стили сайта не влияют), события клавиатуры из панели не доходят до сайта (Enter не отправит сообщение).
- Не переводить повторно одно и то же (кэш, дедупликация, отметки в DOM).
- Не тратить запросы на английский (локальное определение языка до сетевого запроса).
- Устойчивость к ограничениям бесплатного эндпоинта: очередь, ретраи, фолбэк на официальный API.
- Настройка нового сайта без программиста: выбор элементов кликом.

## Нагрузка и объёмы

Исходные данные: ~100 тикетов/час, 20–1000 символов, ~1/3 на иностранных языках.

Допущения для расчёта: средний тикет ~400 символов; ответ оператора ~300 символов; на иностранный тикет в среднем 1 ответ; при правке текста в панели — 1 повторный перевод.

| Поток | Формула | Символов/час |
|---|---|---|
| Входящие иностранные | 33 × 400 | ~13 000 |
| Входящие английские, ушедшие в API (короткие/неуверенные для CLD) | ~10 × 50 | ~500 |
| Исходящие: перевод | 33 × 300 | ~10 000 |
| Исходящие: обратный перевод | 33 × 300 | ~10 000 |
| Исходящие: повторные переводы при правке | 33 × 300 × ~1 | ~10 000 |
| **Итого** | | **~45 000 симв/час** |

Запросов: ~33 входящих + ~33×3 исходящих ≈ **130–150 запросов/час** (≈ 2–3 в минуту) — для бесплатного эндпоинта это немного.

В месяц (8 ч × 22 дня): ~**8 млн символов**. При 24/7 — ~32 млн.

### Стоимость, если перейти на официальный API

Google Cloud Translation (Basic v2): первые 500 000 символов/мес бесплатно, далее $20 за 1 млн.

| Режим работы | Символов/мес | Оценка |
|---|---|---|
| 8×5 | ~8 млн | ~$150/мес |
| 24×7 | ~32 млн | ~$630/мес |

Способы сократить: не делать обратный перевод автоматически (кнопкой) — минус ~20%; фолбэк на API только при сбоях бесплатного — почти $0.

## Ограничения бесплатного варианта (важно)

- `translate.googleapis.com/translate_a/single?client=gtx` — **неофициальный** эндпоинт: нет SLA, Google может ограничить (HTTP 429) или изменить его без предупреждения.
- Все операторы из одного офиса выходят с одного IP — лимит «общий». При текущей нагрузке (2–3 запроса/мин на команду) риск низкий.
- Защита: ретраи + автоматический фолбэк на официальный API, если задан ключ (`fallbackToCloud`).

## Приватность

Тексты сообщений пользователей уходят в Google. Нужно подтвердить, что это допустимо политикой компании (ПДн: email, телефоны, номера карт, документы). В план (v0.3) внесено маскирование ПДн перед отправкой.
