# 06. План версий и риски

## v0.1.0 — прототип ✅
Перевод входящих и исходящих с подтверждением на тестовом чате.

## v0.2.0 — готовность к пилоту ✅
- [x] Поддержка iframe (все фреймы, команды и пикеры во фреймах).
- [x] `optional_host_permissions` и регистрация скриптов только для подключённых доменов.
- [x] Защита от отправки без перевода (Enter / Ctrl+Enter / кнопка) с «Отправить как есть».
- [x] Глоссарий «не переводить» и фиксированные переводы.
- [x] Закрепление языка для тикета.
- [x] Режим вставки «после сообщения» для капризных фреймворков.
- [x] Язык собеседника только из сообщений пользователя.
- [x] Статистика: языки, объёмы, кэш, ошибки, блокировки, оценка стоимости, экспорт, объединение по команде *(перенесено из v0.3)*.

## Пилот на реальном сайте — следующий шаг
См. [07-pilot-plan.md](07-pilot-plan.md).
- [ ] Подключить рабочий сайт, подобрать стабильные селекторы, проверить совместимость вставок и защиты с фреймворком сайта.
- [ ] Пройти непроверенные на dev-стенде пункты (установленный пакет).

- [ ] По итогам — v0.2.x с исправлениями под реальный сайт.

## v0.3.0 — качество и безопасность
- [ ] Маскирование ПДн перед отправкой в переводчик: email, телефоны, номера карт, IBAN, ID транзакций → метки ⟦n⟧ → восстановление (механизм меток уже есть в глоссарии).
- [ ] Шаблоны ответов: заранее переведённые и вычитанные версии частых ответов на топ-языки (топ языков — из статистики пилота).
- [ ] Альтернативные провайдеры: DeepL API, LLM (например, Claude) для исходящих — вежливый тон поддержки.

## v1.0.0 — раскатка на команду
- [ ] Централизованные настройки через политику (`chrome.storage.managed`).
- [ ] Упаковка: приватная публикация в Chrome Web Store / Edge Add-ons или force-install через политику; автообновления.
- [ ] Решение по провайдеру по данным статистики.
- [ ] Централизованная статистика (если нужен онлайн-дашборд вместо объединения файлов).
- [ ] Инструкция для операторов (1 страница) и видео 2 минуты.

## Риски

| Риск | Вероятность | Влияние | Митигирование |
|---|---|---|---|
| Google ограничит/изменит бесплатный эндпоинт | Средняя | Высокое | Ретраи, фолбэк на Cloud API, провайдеры за единым интерфейсом; статистика даёт точную оценку стоимости перехода |
| Сайт не принимает синтетический Enter при повторе отправки | Средняя | Среднее | Задать «Кнопка отправки» — повтор через клик; проверяется первым на пилоте |
| Обработчики сайта на Enter стоят раньше наших (capture на window) | Низкая | Высокое (защита не сработает) | Проверка на пилоте; план Б — перехват на уровне поля + подписка при document_start |
| Вёрстка сайта изменилась — селекторы сломались | Средняя | Среднее | Стабильные атрибуты, автопоиск, перенастройка пикерами за минуты |
| Фреймворк сайта конфликтует со вставками | Низкая–средняя | Среднее | Режим «после сообщения» |
| Ложные срабатывания защиты (ссылки, коды, имена) | Средняя | Низкое | Порог букв, игнор URL, «Отправить как есть» (частоту видно в статистике) |
| Ошибка машинного перевода в ответе | Средняя | Среднее | Подтверждение, обратный перевод, подсветка, глоссарий |
| Политика ПДн запрещает отправку текстов в Google | Неизвестно | Высокое | Согласовать до пилота; маскирование ПДн (v0.3); официальный API с DPA |
| Режим разработчика — ручные обновления, предупреждения Chrome | Высокая | Низкое | v1.0 — приватная публикация / политика |
