# 05. Тестирование (v0.2)

## Окружение
- Сервер: `powershell -ExecutionPolicy Bypass -File support-translator/tools/serve.ps1` (localhost:8787 и 127.0.0.1:8787)
- С расширением: http://localhost:8787/test-site/mock-chat.html → popup → «Подключить этот сайт» (или настройки → правило «Тестовый чат» → «Выдать доступ»)
- Чат во фрейме с другого origin: http://localhost:8787/test-site/mock-iframe.html (доступ нужен и к localhost, и к 127.0.0.1 — у тестового правила оба домена уже в «Доп. доменах»)
- Без расширения (эмуляция chrome.*): добавить `?harness=1` к адресам выше; в консоли `stHarness.command('translate-input')`, `stHarness.pick('message')`, `stHarness.setSettings({...}, {...правило})`, `await ST_STATS.today()`
- Статистика на демо-данных: http://localhost:8787/test-site/stats-preview.html

Тестовый чат: тикеты es, tr, de, en, ru; «+ Входящее» (pt, fr, ar, zh, it, pl, en, «ok»); textarea ↔ contenteditable; Enter и кнопка «Отправить» отправляют; входящие — `.msg.in`, ID тикета — `#chatTitle`.

## Чек-лист регрессии

### Доступ и установка
- [ ] Свежая установка: на mock-chat ничего не происходит, popup — «Сайт не подключён» + кнопка.
- [ ] «Подключить этот сайт» → «Разрешить» → через ~1 с переводы появились без F5.
- [ ] Настройки → у правила «✅ Доступ выдан».
- [ ] `chrome://extensions` → Сведения → «Доступ к сайтам» → удалить localhost → переводы не появляются после F5.
- [ ] Перезагрузить расширение (⟳) не обновляя вкладку → Enter с русским текстом **не** блокируется старым скриптом, тост «обновите страницу».

### Входящие
- [ ] Тикет #1: испанские переведены, «Испанский (es) → Английский». Английские — без подписи.
- [ ] Смена тикета — без дублей подписей. «+ Входящее» — перевод ≤ 2 с; «ok» и английское — без подписи.
- [ ] Режим «Вместо оригинала» и переключатель «оригинал/перевод».
- [ ] «Куда вставлять» = «После сообщения»: подпись — соседний элемент, при смене тикета старые подписи исчезают.
- [ ] Глоссарий (`iPhone 13`, `token expirado`) — термины в переводе без изменений.

### Исходящие
- [ ] Кнопка над полем показывает «→ ES»; в тикете #2 — «→ TR».
- [ ] Панель: язык выбран, обратный перевод, подсветка; Enter в панели не отправляет; Ctrl+Enter вставляет; «Вернуть оригинал».
- [ ] То же в contenteditable.
- [ ] 📌 закрепить de в тикете #2 → переключиться на #1 (es) → назад на #2 → de 📌; снять 📌 → tr.
- [ ] Глоссарий: `Кошелёк => ru: Кошелёк | es: Billetera` → в переводе «Billetera», в обратном — «Кошелёк».

### Защита отправки
- [ ] Тикет #1, русский текст + Enter → сообщение не ушло, предупреждение «Испанский (es) … кириллица».
- [ ] «🌐 Перевести» → панель → Ctrl+Enter → Enter → ушло без предупреждения.
- [ ] Испанский текст, набранный вручную + Enter → ушло (после короткой проверки).
- [ ] Английский текст + Enter → предупреждение «Ваш текст: Английский (en)».
- [ ] «Отправить как есть» → ушло.
- [ ] Русский текст + клик «Отправить» → предупреждение; «Отправить как есть» → ушло.
- [ ] Esc в предупреждении → текст в поле, фокус в поле.
- [ ] «спасибо» / «ok» (меньше 8 букв) → уходит без проверки.
- [ ] Shift+Enter → перенос строки, без проверки.
- [ ] Отправленное «как есть» русское сообщение не меняет язык собеседника (кнопка по-прежнему «→ ES»).
- [ ] Правило → снять «Предупреждать…» → русский текст уходит сразу.

### iframe
- [ ] mock-iframe.html: переводы внутри фрейма; popup показывает «(в iframe)»; пикеры работают внутри фрейма; Ctrl+Shift+Y открывает панель во фрейме.

### Popup / настройки / статистика
- [ ] Popup: язык собеседника, 📌, «защита отправки: вкл», счётчики за сегодня.
- [ ] Пикеры «Кнопка отправки», «ID тикета» → тост с селектором и «найдено: 1».
- [ ] Неверный селектор / домен → сохранение блокируется.
- [ ] Экспорт → файл без API key и `lastOutgoingLang`; импорт восстанавливает правила.
- [ ] «Проверить глоссарий» показывает метки ⟦n⟧ и результат.
- [ ] Статистика: плитки, график по дням (подсказка при наведении), языки, стоимость, таблица; 7/30/90 дней; экспорт JSON/CSV; «+ Файлы коллег» суммирует; «Сбросить».
- [ ] Статистика не задваивает входящие при F5 страницы.

## Результаты прогонов

### 0.2.2 — dev-стенд, 2026-09-17
- `mock-chat.html?harness=1&shadow=1` (интерфейс в Shadow DOM): переводы внутри shadow root со стилями; новые входящие подхватываются; защита отправки блокирует русский текст, «Перевести» → вставка → Enter отправляет; пикер сообщения выбирает элемент внутри shadow root; двухшаговый пикер нашёл `.in`; диагностика видит shadow root, поле ввода, текстовые блоки.
- Обычный режим: синтаксис всех файлов, стили через adoptedStyleSheets.
- **Во время прогона Google начал отклонять запросы из браузера с этого IP** (после нескольких сотен тестовых запросов за день; из PowerShell адрес в тот же момент отвечал). Добавлен предохранитель; повторная проверка перевода — после снятия ограничения.

### 0.2.1 — dev-стенд, 2026-09-17
- Письмо в `iframe srcdoc` (тикет #6): фрейм сопоставлен с правилом по адресу родителя, документ фрейма — одно сообщение, перевод pt → en отрисован во фрейме.
- Диагностика в dev-стенде: правило, счётчики, iframe (srcdoc, same-origin, размер), Shadow DOM, текстовые блоки — без текста сообщений.
