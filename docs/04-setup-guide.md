# 04. Установка и настройка (v0.2)

## Установка (оператор)

1. Получить папку расширения (распакованный zip из `versions/`) и положить в постоянное место — **не в «Загрузки»**: если папку удалить или переместить, расширение пропадёт вместе с настройками.
2. Chrome: `chrome://extensions` (Edge: `edge://extensions`) → **Режим разработчика**. Firefox и Safari — см. ниже.
3. **Загрузить распакованное** → папка, где лежит `manifest.json`.
4. Закрепить иконку 🌐 (значок пазла → булавка).
5. Правый клик по иконке → «Параметры» → **Импорт из файла** → файл настроек от тимлида.
6. В настройках у правила сайта нажать **Выдать доступ** → «Разрешить». (Или открыть сайт → иконка → **Подключить этот сайт**.)
7. Обновить (F5) вкладку сайта поддержки.

### Firefox и Safari

- **Firefox 128+**: тимлид собирает пакет — `powershell -ExecutionPolicy Bypass -File tools/build-firefox.ps1` (готовая папка и zip в `dist/`). Установка: `about:debugging#/runtime/this-firefox` → **«Загрузить временное дополнение»** → `manifest.json` из `dist/firefox-v*/`. Временное дополнение слетает при перезапуске браузера; для постоянной установки нужна подпись на addons.mozilla.org.
- **Safari 17+ (macOS)**: `xcrun safari-web-extension-converter extension`, затем сборка и запуск в Xcode; в Safari включить расширение в «Настройки → Расширения».
- В обоих браузерах нет встроенного переводчика Chrome, поэтому перевод идёт через облако (бесплатный Google или Google Cloud по ключу). Остальное работает одинаково.

Горячие клавиши меняются в `chrome://extensions/shortcuts`.

### Обновление с 0.1.0
Заменить содержимое папки расширения → `chrome://extensions` → ⟳ → **выдать доступ к сайту** (п. 6) → F5 на вкладке. В 0.2 расширение не работает на сайтах, к которым не выдан доступ.

## Ежедневная работа

| Действие | Как |
|---|---|
| Прочитать сообщение пользователя | Перевод появляется под сообщением автоматически |
| Посмотреть оригинал (режим «вместо») | «оригинал» в подписи |
| Перевести ответ | Написать ответ → **🌐 Перевести → ES** над полем (сочетание клавиш можно назначить в chrome://extensions/shortcuts) |
| Проверить перевод | Сравнить свой текст с «Обратным переводом», жёлтые слова — места для проверки |
| Вставить | **Ctrl+Enter** или «✔ Вставить перевод», затем отправить как обычно |
| Передумал | **Esc**; после вставки — «↩ Вернуть оригинал» или Ctrl+Z |
| Пользователь пишет на смеси языков / язык определился неверно | В панели выбрать язык и отметить **📌 закрепить для тикета** |
| Появилось «⚠ Похоже, сообщение не переведено» | **🌐 Перевести** (Enter) — или «Отправить как есть», если так и задумано (ссылка, код, имя) |
| Перевод не появился | **Ctrl+Shift+U** или popup → «↻ Перевести заново» |
| Статистика | popup → «Статистика» |
| Пишу внутреннюю заметку | Переключите композер в «Note» — защита и кнопка перевода отключаются сами |
| Красная плашка «🔢 Проверьте числа и ссылки» | Сумма, дата, телефон, ID или ссылка в переводе отличаются от оригинала — исправьте перевод; «⚠ Вставить всё равно» — если расхождение ожидаемо |
| Плашка «🤝 Перевод обращается на «ты»» | «Перевести вежливо («Вы»)» или поправьте вручную |
| Плашка «✏️ Возможно, опечатка» | «Исправить и перевести» |
| Метка `ES`/`TR` в списке тикетов | Язык тикета — видно до открытия |
| Значок `!` / `•` на иконке расширения | Самопроверка нашла проблему — откройте popup, там список |

## Настройка сайта (тимлид)

### Через popup (рекомендуется)
См. процесс П4 в [03-processes.md](03-processes.md#п4-подключение-нового-сайта-тимлид-10-минут).

### Поля правила

| Поле | Что указать | Пример |
|---|---|---|
| Шаблон URL | Где включать: страница и/или URL iframe чата. `*` — любые символы, через запятую | `https://desk.company.com/tickets/*` |
| Доп. домены доступа | Только если домен нельзя вывести из шаблона (шаблон начинается с `*`) | `https://desk.company.com/*` |
| Окно(а) чата | Область сообщений | `#chat-messages` |
| Сообщение | Элемент **с текстом** сообщения (без автора и времени). Пусто — автопоиск (менее точно) | `.message__text` |
| Сообщение пользователя | Селектор, который есть у входящих сообщений (или их контейнера) и нет у сообщений оператора | `.message--incoming`, `[data-author="client"]` |
| Поле ввода | Поле ответа. Пусто — любое поле | `textarea[name="reply"]` |
| Кнопка отправки | Для защиты отправки кликом | `button[type="submit"]` |
| ID тикета | Номер/ID тикета в шапке. Пусто — URL страницы | `.ticket-header__number` |
| Отправка с клавиатуры | Как сайт отправляет: Enter / Ctrl+Enter / только кнопкой | Enter |
| Куда вставлять перевод | «Внутрь сообщения»; если подписи пропадают/дублируются или сайт выдаёт ошибки — «После сообщения» | Внутрь |
| Предупреждать об отправке… | Защита отправки для этого сайта | ✔ |

Как найти селектор в DevTools: правый клик по элементу → «Просмотреть код» → искать `id`, `data-testid`/`data-qa`, осмысленные классы. Избегать классов вида `css-1x2y3z`, `sc-AbCd`. Проверка в консоли: `document.querySelectorAll('.message__text').length`.

### Если ничего не переводится
1. Popup → **🩺 Диагностика** — отчёт скопируется в буфер (без текста переписки: только структура страницы, селекторы и счётчики).
2. Вставить отчёт разработчику. По нему видно: подошло ли правило, сколько сообщений найдено, есть ли iframe/Shadow DOM и какие элементы похожи на сообщения.

Частые причины: не выбрано «Окно чата» (с 0.2.2 без него перевод не запускается); сообщение выбрано пикером не на тексте, а на обёртке/служебной надписи; письма показываются во фрейме (с 0.2.1 распознаются автоматически); интерфейс сайта в Shadow DOM (с 0.2.2 поддерживается).

Порядок настройки на сайте с открытым тикетом: **1. Окно чата** (кликнуть по пустому месту ленты сообщений) → **2. Сообщение** (по тексту сообщения пользователя) → **3. Поле ввода** → **4. Кнопка отправки** → **6. Сообщение пользователя vs оператора** (сначала по сообщению пользователя, потом по своему) → **7. Превью в списке тикетов** (по тексту последнего сообщения в списке) → **8. Тема письма** (в шапке тикета). После каждого шага смотрите тост: сколько элементов найдено.

### Сообщения пользователя и агентов
Чтобы входящие переводились сами, а сообщения агентов — по кнопке:
1. **2. Сообщение** — селектор должен охватывать тексты **всех** сообщений (и пользователя, и агентов, и письма, и чат). Если пикер выбрал только один вид — впишите в настройках несколько селекторов через запятую.
2. **6. Сообщение пользователя vs оператора** — сначала клик по сообщению пользователя, затем по сообщению агента. Если сообщения агента выровнены вправо классом (`justify-end` и т.п.), получится селектор вида `[data-testid^="…"]:not(.justify-end)` — он подходит и для писем, и для чата.
3. Настройки правила → **«Сообщения агентов»**: «по кнопке» (экономит запросы), «автоматически» или «не переводить».
4. Проверка: 🩺 Диагностика → `found.messageBreakdown` — сколько сообщений пользователя и агентов найдено.

### Режим заметки
Если защита срабатывает на внутренних заметках: переключите композер в режим заметки → popup → **🩺 Диагностика** → в отчёте `found.noteModeNow` и `found.noteModeReason` (какой элемент совпал). Если в режиме Reply/Email там `true` — пришлите отчёт разработчику. Если в режиме заметки `false` — в настройках правила впишите в «Режим заметки: подписи» точный текст переключателя (например, `Note`) или задайте «Режим заметки: селектор» — элемент, который виден только в режиме заметки.

### Самопроверка
Значок на иконке: `!` (красный) — окно чата найдено, но сообщения не находятся (скорее всего сайт обновил вёрстку — перенастройте «2. Сообщение»); `•` (оранжевый) — предупреждения (не выбрано окно, не найдено поле ввода, лимит Google, ошибки перевода). Подробности — в popup.

### Если чат в iframe
1. DevTools → найти `<iframe src="…">` вокруг чата → скопировать домен `src`.
2. Правило → **Шаблон URL**: добавить через запятую URL фрейма, например `https://desk.company.com/*, https://chat.vendor.com/*`.
3. **Выдать доступ** (появятся оба домена).
4. F5. Пикеры popup работают внутри фрейма — кликать по элементам чата как обычно.

## Глоссарий

Настройки → «Глоссарий», по строке на запись:
```
# не переводить
Premium Plus
SupportDesk
# фиксированный перевод (для языков, которых нет в списке, переводит Google)
Кошелёк => ru: Кошелёк | es: Billetera | tr: Cüzdan | en: Wallet
Вывод средств => ru: Вывод средств | es: Retiro | en: Withdrawal
```
- Регистр не важен, ищутся целые слова/фразы.
- Для фиксированных терминов указывайте и язык операторов (`ru: …`) — тогда обратный перевод вернёт тот же термин.
- «Проверить глоссарий» показывает, что уходит в переводчик и что получилось.
- Известный эффект: слово рядом с термином иногда получает не тот артикль/предлог («a iPhone»). Проверяйте обратным переводом.

## Языки операторов
Настройки → «Языки операторов» (по умолчанию `ru`). Сообщения на этих языках не считаются языком собеседника. Если на сайте задан «Сообщение пользователя» — этот список не используется (надёжнее). Если среди пользователей есть русскоязычные, обязательно задайте «Сообщение пользователя».

## Как меньше упираться в лимиты Google
1. **Перевод на устройстве.** Настройки → «Перевод на устройстве» → режим «Для всего» → впишите языки собеседников → **«Проверить пакеты»** → «Скачать» у каждой нужной пары или **«Скачать все недостающие»** (один раз на компьютер, нужен Chrome или Edge 138+; в Firefox и Safari этого раздела нет — перевод идёт через облако; пакеты качаются в обе стороны — для входящих, ответов и обратного перевода). Всё переводится сначала без интернета и без лимитов, облако — только если пакета нет. Там же — модели на устройстве (определение языка, Gemini Nano для «Вежливее» и «Кратко о тикете») с отдельной кнопкой «Скачать». Если пакета не хватило во время ответа, в панели появится кнопка «⬇ Скачать пакет».
2. **Резерв Google Cloud.** Создайте ключ (инструкция в настройках под полем ключа), вставьте в «Google Cloud API key (резерв)», включите «Резерв…», нажмите **«Проверить резерв Google Cloud»**. При блокировке бесплатного Google переводы продолжат приходить.
3. «Переводить входящие только когда сообщение на экране» и «Объединять сообщения одного языка» — включены по умолчанию, трогать не нужно.

## Провайдер
- По умолчанию **Google бесплатный** — ключ не нужен.
- Официальный API: Google Cloud Console → проект → **Cloud Translation API** → Credentials → API key (ограничить ключ только Translation API) → вставить в настройки. Либо основным провайдером, либо резервным («переключаться на официальный»).
- «Проверить перевод» показывает провайдера, язык и время ответа.

## Помощник агента (0.7)

Настройки → **«Помощник агента»**:

| Функция | Как пользоваться |
|---|---|
| ⚡ Быстрая вставка | Shift+клик по «🌐 Перевести» — перевод сразу в поле, без панели. Можно сделать режимом по умолчанию (тогда Shift+клик открывает панель). Если числа/ссылки не совпали или перевод на «ты» — откроется панель. |
| 🧠 Память переводов | Всё, что вы вставили через панель (с вашими правками), запоминается. Тот же текст на тот же язык переводится мгновенно; в панели пометка и кнопка «Перевести заново». Выгрузка и очистка — в настройках. |
| ✨ Локальная модель | В панели ответа: «Исправить / Вежливее / Короче / Проще». Модель Chrome работает с английским: текст → английский → правка → язык клиента. Chrome/Edge 138+, модель (~2 ГБ) скачивается при первом использовании. «Проверить локальную модель» — в настройках. |
| 🧠 Кратко о тикете | Кнопка «🏷 тема» у поля ввода, «⋯» → «Кратко о тикете» или меню расширения. Что хочет клиент, пересказ, настроение, подходящие макросы. Без модели — тема по ключевым словам и первые фразы сообщений. |
| 🏷 Макросы для тем | Строки `refund: ref recur 3m, ref ups` — какие макросы подсказывать для темы. |
| 🔀 Смена языка | Клиент перешёл на другой язык — подсказка; если язык ответа закреплён 📌, кнопка «Снять 📌». |
| ⋯ Палитра команд | Кнопка «⋯» у поля ввода или своё сочетание клавиш (chrome://extensions/shortcuts → «Палитра команд»). Поиск по командам, ↑↓, Enter. |
| 🔧 Самопроверка | Если селекторы сайта ~15 с ничего не находят (сайт обновил вёрстку) — предупреждение на странице с кнопкой «Настройки». |
| ⬆ Обновления | Раз в 12 часов расширение сверяет версию с GitHub и напоминает об обновлении (один раз на версию). |
| 🔒 Персональные данные | Почты, телефоны, карты, IBAN и номера заказов заменяются метками перед отправкой в облачный переводчик и возвращаются в перевод. Если переводчик потерял метку — перевод повторяется без маскирования, данные не пропадают. |
| 💶 Лимит Google Cloud | Расход за месяц — в меню расширения и настройках; при 80% предупреждение, при 100% Cloud отключается до 1-го числа (можно выключить). |
