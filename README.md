# Support Translator

Расширение (Manifest V3) для команды тех.поддержки, работающей в веб-мессенджере. Браузеры: Chrome и Edge (папка `extension/`), Firefox (пакет из `tools/build-firefox.ps1`), Safari (та же папка после конвертации в Xcode) — см. «Браузеры» ниже.

- **Входящие** — сообщения пользователей в заданных «окнах» автоматически переводятся на английский, под каждым переводом подпись *🌐 Переведено: Испанский (es) → Английский* и кнопки «скрыть / оригинал / копировать».
- **Исходящие** — введённый оператором текст переводится на язык собеседника **только через панель подтверждения**: оригинал | перевод (можно править) | обратный перевод с подсветкой расхождений. В поле вставляется только после «Вставить перевод», отправку делает оператор.
- **Защита отправки** — если оператор пытается отправить текст не на языке собеседника, расширение останавливает отправку и предлагает перевести.
- **Проверки перевода ответа** — числа/суммы/телефоны/ссылки должны совпадать, предупреждение об обращении на «ты», подсказка опечаток.
- **Удобство в хелпдеске** — внутренние заметки не трогаются, абзацы сохраняются, тёмная тема, метки языка в списке тикетов, перевод темы письма, язык из письма во фрейме, самопроверка со значком на иконке.
- **Глоссарий**, **закрепление языка за тикетом**, **iframe и Shadow DOM**, **доступ только к подключённым сайтам**, **статистика** с оценкой стоимости, **диагностика**.
- **Провайдер** — бесплатный эндпоинт Google Translate; опционально официальный Google Cloud Translation API (ключ) как основной или резервный.
- **Помощник агента (0.7)** — быстрая вставка перевода без панели, память переводов (ваши подтверждённые переводы с правками), правка ответа локальной моделью Chrome («Исправить / Вежливее / Короче / Проще»), «Кратко о тикете» и тема обращения с подсказкой макросов, предупреждение о смене языка клиентом, палитра команд, самопроверка селекторов, уведомление о новой версии, лимит Google Cloud, скрытие персональных данных от облачного переводчика, арабский справа налево, знакомство с расширением.

## Браузеры

| Браузер | Что нужно | Особенности |
|---|---|---|
| Chrome 138+ | папка `extension/` (Режим разработчика → «Загрузить распакованное») | всё работает, перевод на устройстве |
| Edge 138+ | та же папка (`edge://extensions`) | как Chrome |
| Firefox 128+ | `powershell -File tools/build-firefox.ps1` → `dist/firefox-v*/` (about:debugging → «Загрузить временное дополнение») | перевод только через облако (Translator API есть лишь в Chrome/Edge); письма во вложенных `about:srcdoc`-фреймах не переводятся |
| Safari 17+ | `xcrun safari-web-extension-converter extension` и сборка в Xcode | перевод только через облако |

Всё остальное — входящие, панель перевода ответа, защита отправки, проверки, глоссарий, статистика, диагностика — одинаково во всех браузерах.

Текущая версия: **0.7.2** — см. [CHANGELOG.md](CHANGELOG.md). Следующий шаг — [пилот на реальном сайте](docs/07-pilot-plan.md).

## Быстрый старт

1. `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное» → выбрать папку `support-translator/extension`.
2. Запустить тестовый сервер:
   ```bash
   powershell -ExecutionPolicy Bypass -File support-translator/tools/serve.ps1
   ```
3. Открыть http://localhost:8787/test-site/mock-chat.html → иконка расширения → **Подключить этот сайт** → разрешить.
4. Входящие на иностранных языках получат перевод. Написать ответ по-русски и нажать Enter — сработает защита; **🌐 Перевести** → **Ctrl+Enter** → Enter.

Настройка под реальный сайт: [docs/04-setup-guide.md](docs/04-setup-guide.md).

## Версионирование

- Разработка идёт в `extension/`.
- Выпуск версии: поднять `version` в `extension/manifest.json`, дописать `CHANGELOG.md`, выполнить
  ```bash
  powershell -ExecutionPolicy Bypass -File support-translator/tools/release.ps1
  ```
  Скрипт скопирует `extension/` в `versions/vX.Y.Z/` и создаст `versions/support-translator-vX.Y.Z.zip`. Существующую версию не перезаписывает.
